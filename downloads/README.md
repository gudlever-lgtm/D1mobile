# Hent Askegrav til Android

Scan QR-koden med din Android-telefon:

![Hent Askegrav APK](askegrav-qr.png)

[Hent APK direkte](https://github.com/gudlever-lgtm/D1mobile/raw/refs/heads/build/downloads/askegrav-debug.apk)

Version **0.3.0**: mere detaljerede, originale D1-inspirerede sprites og ganganimationer til helten, skeletter, dæmoner og bossen. Monstre venter nu, indtil helten kommer inden for tre gulvfelter med fri sigtelinje, eller de selv rammes. Mure og murhjørner blokerer angreb.

![Spilbillede](askegrav-gameplay.png)

Dette er en debug-build. Android kan bede dig tillade installation fra browseren. Hvis repositoriet er privat, skal du være logget ind på GitHub med adgang til det. APK-filen kan ikke installeres på iPhone.

SHA-256 findes i `askegrav-debug.apk.sha256`.

0.2.1 retter en låsning, når trappens lys vises på et ryddet niveau. Opsamling af klinger, våbenopgraderinger og fortsat spil efter rydning af niveauet er dækket af browserregressioner.
